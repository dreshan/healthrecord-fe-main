# Project Separation Guide

## How to Create Two Separate Projects

This guide shows you how to split this codebase into two separate projects:
- **healthrecordfe** (React Frontend)
- **healthrecordbe** (Spring Boot Backend)

---

## Step 1: Create Frontend Project (healthrecordfe)

### Files to Copy

Create a new folder `healthrecordfe` and copy these files/folders:

```
healthrecordfe/
├── src/                          # Copy entire src folder
├── public/                       # If exists
├── .gitignore                    # Copy
├── eslint.config.js             # Copy
├── index.html                   # Copy
├── package.json                 # Copy
├── package-lock.json            # Copy
├── postcss.config.js            # Copy
├── tailwind.config.js           # Copy
├── tsconfig.app.json            # Copy
├── tsconfig.json                # Copy
├── tsconfig.node.json           # Copy
├── vite.config.ts               # Copy
├── .env.example                 # Copy (rename to .env and configure)
├── README_FRONTEND.md           # Copy as README.md
└── PROJECT_OVERVIEW.md          # Copy for reference
```

### Files to EXCLUDE from Frontend

Do NOT copy:
- ❌ `supabase/` folder
- ❌ `DATABASE_SCHEMA_MYSQL.md`
- ❌ `SPRING_BOOT_API_SPECIFICATION.md`
- ❌ `SPRING_BOOT_SETUP_GUIDE.md`
- ❌ `src/lib/supabase.ts` (already removed)

### Frontend Setup Commands

```bash
cd healthrecordfe
npm install
cp .env.example .env
# Edit .env and set: VITE_API_BASE_URL=http://localhost:8080/api
npm run dev
```

## Step 2: Create Backend Project (healthrecordbe)

### Create Spring Boot Project

1. Go to [Spring Initializr](https://start.spring.io/)

2. Configure:
   - **Project**: Maven
   - **Language**: Java
   - **Spring Boot**: 3.2.x
   - **Group**: com.healthtrack
   - **Artifact**: healthrecordbe
   - **Packaging**: Jar
   - **Java**: 17

3. Add Dependencies:
   - Spring Web
   - Spring Security
   - Spring Data JPA
   - MySQL Driver
   - Lombok
   - Validation

4. Generate and extract

### Copy Documentation to Backend

From this project, copy these files to your `healthrecordbe` folder:

```
healthrecordbe/
├── src/                                    # Generated by Spring Initializr
├── pom.xml                                 # Generated by Spring Initializr
├── DATABASE_SCHEMA_MYSQL.md               # Copy from this project
├── SPRING_BOOT_API_SPECIFICATION.md       # Copy from this project
├── SPRING_BOOT_SETUP_GUIDE.md            # Copy from this project
└── README.md                              # Create new (see below)
```

### Backend README.md

Create `healthrecordbe/README.md`:

```markdown
# Health Record Tracker - Backend

Spring Boot REST API for Health Record Tracker system.

## Tech Stack

- Spring Boot 3.2+
- Spring Security + JWT
- Spring Data JPA
- MySQL 8.0+
- Lombok

## Setup

1. Install MySQL and create database:
   ```sql
   CREATE DATABASE healthtrack;
   ```

2. Run schema from `DATABASE_SCHEMA_MYSQL.md`

3. Configure `src/main/resources/application.properties`:
   ```properties
   spring.datasource.url=jdbc:mysql://localhost:3306/healthtrack
   spring.datasource.username=root
   spring.datasource.password=your_password
   jwt.secret=your_secret_key_minimum_256_bits
   jwt.expiration=86400000
   cors.allowed.origins=http://localhost:5173
   ```

4. Run application:
   ```bash
   ./mvnw spring-boot:run
   ```

## Implementation

Follow `SPRING_BOOT_SETUP_GUIDE.md` for complete implementation guide.

See `SPRING_BOOT_API_SPECIFICATION.md` for all API endpoints.

## Database

See `DATABASE_SCHEMA_MYSQL.md` for complete schema.
```

### Backend Setup Commands

```bash
cd healthrecordbe
./mvnw spring-boot:run
```

## Key Points

### Frontend (healthrecordfe)
- Pure React/TypeScript application
- No backend code
- No database migrations
- Communicates via REST API
- Environment: Node.js + npm

### Backend (healthrecordbe)
- Pure Spring Boot application
- No frontend code
- Handles database
- Provides REST API
- Environment: Java + Maven + MySQL

### Communication
- Frontend calls backend via HTTP
- Backend exposes REST API at `/api/*`
- Authentication via JWT tokens
- CORS enabled for cross-origin requests

## Deployment

### Frontend
- Deploy to: Vercel, Netlify, AWS S3
- Build command: `npm run build`
- Output directory: `dist/`
- Environment: Set `VITE_API_BASE_URL`

### Backend
- Deploy to: AWS, Heroku, Railway, DigitalOcean
- Build command: `./mvnw clean package`
- Run command: `java -jar target/*.jar`
- Environment: Set database URL, JWT secret

### Database
- Deploy to: AWS RDS, PlanetScale, Railway
- Import schema from `DATABASE_SCHEMA_MYSQL.md`
- Update backend connection string
